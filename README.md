# Devotion-VR-Mod
Vr Mod for Devotion


DEVOTION VR  (BepInEx 5 mod, Unity 2020.2 Mono)
================================================


INSTALL
1.unzip into the Devotion folder (it adds BepInEx\plugins\DevotionVR).
3. Start SteamVR / Oculus / Virtual Desktop (the OpenXR runtime), then start the game.

CONTROLS (Xbox layout - the game shows Xbox buttons)
-
  Left stick ............ walk (forward = where you look)
  
  Right stick ........... turn (snap\smooth) in menus, close-ups and puzzles it is the game's right stick
  
  A ..................... interact / confirm
  
  B ......... back
  
  X ..................... notes
  
  Y ......... items / notebook
  
  Left trigger .......... lighter
  
  Right trigger ... focus
  
  Grips ................. bumpers
  
  X + Y ........... pause
  
  Left stick click ...... run (until you stop) **[added small sprint]**
  
  Hold left grip 2.1 s ... flashlight **[added flashlight beam]**
  
  Both stick clicks ............... re-centre the view **[if game start to high from floor level]** 
  
  Both stick hold ............... 1.2 s = VR settings menu
  
  Right grip + right stick click .. switch what you aim with: head -> right controller -> left controller
  
  Both grips + A .................. adjust the game hand: it stays where it is, put your controller into it,the way you want to hold it and pull that controller's trigger (B cancels)

THE GAME HAND
-
  The game's arm / hand with the lighter follows your right controller in normal play ([Hands] LighterHand =
  Left for the left one). In cutscenes, animations, close-ups and menus the game moves it as usual.

AIM
  [Aim] AimMode = Head, RightController or LeftController with a short line shows where you point.
